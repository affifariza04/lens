Search photos by meaning,
not by filename.

Type anything. A vision-language model running inside your browser ranks every photo by how well it matches, with no server and no API key.

Preparing…

01 · Build time

Each photo is embedded once with CLIP's image encoder (Node, same model and quantisation) into a 512-d vector, shipped as a 260 KB JSON.

02 · In your browser

The text encoder (≈ 64 MB, quantised to int8) downloads once and is cached. Your query becomes a vector in a few milliseconds.

03 · Ranking

Cosine similarity against every photo, softmax at CLIP's logit scale for a confidence, and a FLIP animation to re-order the grid.
